================================================================================
MotoGuard IoT — Visualizar Base de Dados
================================================================================

PRÉ-REQUISITOS:
1. cd app
2. copy .env.example .env
3. npm run prisma:studio

--------------------------------------------------------------------------------
COMANDOS (dentro da pasta app):
--------------------------------------------------------------------------------

npm run db:view          # Estatísticas
npm run db:trips         # Viagens
npm run db:events        # Eventos
npm run db:motas         # Motas
npm run db:users         # Utilizadores

npm run prisma:studio    # Interface web: http://localhost:5555
