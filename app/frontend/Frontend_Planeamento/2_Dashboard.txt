Layout Principal: 3 Filas de Cards

FILA 1 — Métricas do Motor & IMU


Card 1: GaugeCard (Velocidade)

┌──────────────────┐
│  VELOCIDADE             │
│   ┌─────────────┐ │
│   │    185           │ │
│   │    km/h          │ │
│   └─────────────┘ │
│  Status: ✓ Normal      │
└──────────────────┘

Gauge visual (velocímetro tipo agulha)
-Valor numérico grande (185 km/h)
-Cor dinâmica: verde (normal), amarelo (warning), vermelho (crítico)
-Velocidade máxima atingida na sessão
-Trending: ↑ (acelerando) / ↓ (desacelerando) / → (constante)


Card 2: GaugeCard (RPM)

┌──────────────────┐
│  RPM             	  │
│   ┌─────────────┐ │
│   │   7,500     	│ │
│   │   rpm            │ │
│   └─────────────┘ │
│  Gear: 4 / 6   	  │
└──────────────────┘

-Gauge circular (mostrador RPM)
-Indicador de gear (4/6)
-Zona vermelha indicada
-Comportamento: aceleração/desaceleração


Card 3: TempVoltCard (Múltiplas Leituras)

┌──────────────────┐
│ TEMPERATURA     	  │
│ Eng: 92°C ⚠️    	  │
│ Oil: 85 bar    	  │
│                 	  │

│                 	  │
│ PNEUS           	  │

│ Rear: 2.2 bar   	  │

-Temperatura do motor: valor + cor (verde < 85°C, amarelo 85-100, vermelho > 100)
-Pressão de óleo: bar
-Voltagem da bateria: Volts com indicador de saúde
-Pressões de pneu: Front + Rear (alerta se abaixo do normal)
-Ícones de alerta(⚠️): para valores críticos

┌──────────────────┐

│ Máximo: 2.1G 🟡 	  │

└──────────────────┘

-Lean angle (Roll): graus com indicador visual (verde < 45°, amarelo 45-70°, vermelho > 70°)
-Pitch & Yaw: ângulos complementares
-G-force: Aceleração atual e máxima, com alerta de limiar crítico
-Cores para estados de segurança

-Modelo Selector: Dropdown com 8 modelos (Scooter, Naked, Desportiva, Trail, Cruiser, Motocross, Touring, Supermotard)

-Botões de Evento:
 -"Simular Queda" (Fall event)
 -"Simular Alternador" (Alternator failure)
 -"Simular Overheating" (Overheat event)
 -"Reset Events" (Clear all)

-Message Log: Últimas 100 mensagens, scroll automático, timestamp
-Cards com ícones temáticos (⬇️ queda, ⚡ alternador, 🔥 calor, ✓ reset)

-Estados Especiais
 -Carregando: Skeleton loaders nos cards
 -Sem conexão: Badge vermelha no header "OFFLINE"
 -Evento crítico: Cards piscam ou mudam de cor
 -Notificação: Toast/alert no topo se evento crítico detectado

-Interações
 -Clicar no selector de moto: muda toda a telemetria
 -Clicar em botão de evento: envia comando ao backend via REST/WebSocket
 -Clicar no mapa: expande fullscreen
 -Clicar card individual: pode expandir para fullscreen

Dados
 -Actualizados via Socket.IO em tempo real (sub-segundo)
 -Fallback para polling a cada 2s se WebSocket cair
