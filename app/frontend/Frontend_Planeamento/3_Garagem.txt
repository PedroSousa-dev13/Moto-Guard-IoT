Card de Motocicleta (Detalhes)
-Nome customizável (ex: "Minha Yamaha")
-Modelo: Tipo selecionado (MT-09, CB500F, etc)
-Status Online/Offline: Indicador com cor (🟢 verde online, 🔴 vermelho offline)
-Odómetro: Distância total acumulada
-Última atualização: Timestamp relativo

-Health Score: Barra de progresso baseada em:
 -Eventos críticos (quedas, overheating)
 -Tempo desde última leitura
 -Estado dos sistemas

-Botões de Ação:
 -"Monitorizar" → Vai para Dashboard com esta moto selecionada
 -"Ver" → Abre modal de detalhes completos
 -"Editar" → Abre modal de edit
 -"Remover" → Confirma e remove

Campos do Formulário
-Nome: Campo de texto, obrigatório
-Modelo: Dropdown com 8 opções (cada com ícone representativo)
-Device ID: Campo de texto (MQTT identifier único)
-Ano: Numeric input ou date picker
-VIN: Campo de texto opcional

Estados
-Carregando: Skeleton cards
-Sem motos: Mensagem "Nenhuma moto registada. Começar agora!"
-Ligado/Desligado: Visual claro do status online
