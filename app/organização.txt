#  FASE 3 — LÓGICA HEURÍSTICA E DETEÇÃO        [POR FAZER]
# ═════════════════════════════════════════════════════════════════════════════
#  Corresponde ao Objetivo 3 da proposta.
#
#  [ ] 3.1  Motor de regras heurísticas no backend
#           → Recebe telemetria em tempo real e aplica regras
#           → Configurável por modelo de mota (thresholds do config.py)
#
#  [ ] 3.2  Deteção de eventos de risco
#           → Travagem brusca: desaceleração > X G + brakes > 80%
#           → Vibração anómala: picos em accel_z fora do padrão
#           → Inclinação excessiva: roll > threshold do modelo
#           → Sobreaquecimento: temp > limiar durante Y segundos
#           → Falha de alternador: voltagem a descer progressivamente
#           → Queda confirmada: G-force + roll + imobilidade
#
#  [ ] 3.3  Classificação de severidade
#           → INFO: leituras fora do habitual mas não perigosas
#           → WARNING: valores em zona de atenção
#           → CRITICAL: evento de risco confirmado
#
#  [ ] 3.4  Análise preditiva simples
#           → Tendência de temperatura (vai sobreadecer em X minutos?)
#           → Padrão de voltagem (alternador a falhar?)
#           → Desgaste de pneus (pressão a descer consistentemente?)
#
#  [ ] 3.5  Cruzamento com dados externos
#           → API meteorológica: alertas de precipitação na rota
#           → Condições reportadas pela comunidade (Fase 2.6)
